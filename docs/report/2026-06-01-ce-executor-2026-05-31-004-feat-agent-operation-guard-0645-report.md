## 2. 为什么要做这件事

Ralph 编排系统允许多个"角色化子代理"协作执行任务。在 P0（事件溯源稳定化）和 P1（共享操作上下文）完成后，**已具备授权数据基础**，但**任务生命周期还没有真正启用防护**——任何角色、任何循环都能对任意任务执行"开始 / 完成 / 失败 / 重启"，存在越权与误改风险。

本步骤是 12 步防护计划的第一个"真正启用拦截"步骤：
- 给任务加一个"所有者角色"字段（创建任务时自动打上）
- 拦截"开始 / 完成 / 失败 / 重启"四条命令，必须校验"我在哪个循环"和"我是哪个角色"是否对得上任务的归属
- 允许配置"协调器角色"白名单，被列入的角色可跨角色操作（典型场景：协调员统一调度）
- 同时保护任务"去重"逻辑：相同关键字的任务在不同循环下不互相冲突

**业务价值**：在多循环并行场景下，每个循环只能动自己的任务；协调器统一管理时不会因为误传任务标识而误改其他角色任务；旧的无归属任务保持可见可读（兼容现有数据）。
