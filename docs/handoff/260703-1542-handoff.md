# 关键决策和理由

1. **在 validator 中注入 virtual supervisor，而不是改 preset 显式声明 supervisor hat**
   - 理由：supervisor 是 runtime 隐式构造的，preset 里不存在该 hat；让 validator 在 `config.event_loop.supervisor.enabled` 时模拟其行为，保持 preset 与 runtime 一致。
2. **TopologyGraph 存 hat ID 而非 `&Hat`**
   - 理由：virtual supervisor 没有对应的 `Hat` 实体，用 owned string 可以同时兼容真实 hat 和虚拟 hat。
3. **coordinator 不再监听 wave complete 事件，改由 supervisor 隐式处理**
   - 理由：supervisor 模式下山峰/波浪 completion 由 supervisor 聚合 unit 结果后发布，coordinator 直接监听会导致拓扑重复或 lint 失败。
